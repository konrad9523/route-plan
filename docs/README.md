# 文档导航

这里收录项目说明、设计资料、学习材料和阶段性验证记录。文档用途不同，不能把所有内容都当作当前代码状态。

## 阅读约定

- **当前说明**：用于了解当前项目或接口；涉及文件结构、测试数量和实现状态时，仍应以代码为准。
- **设计参考**：记录方案、架构和建议，不代表这些功能已经实现。
- **历史快照**：保留特定日期的学习过程、实现状态或实测结果。适合回顾依据和过程；使用前先核对日期及当前代码。
- 开源项目、外部文档和下载地址可能变化，按需重新核对。
