## 三点说明

**Issue/PR 模板必须留在 `.github/`，变更日志必须留在仓库根目录**——GitHub 从约定位置读取模板。这里只提供导航，**不复制模板内容**，避免产生两个需要同步的版本。

**角色成果区不在本目录**，而在共享仓库根目录的 [`workspaces/`](../../workspaces/)。
它按五个角色定制结构，用于展示各角色的**对外成果**；制度说明见管理原则文件第 2、3 节。

**个人阶段工作区不在共享仓库**。每人在自己的 Fork 里维护 `member_workspaces/<成员代号>/`，
阶段性推送只更新自己的 Fork，不影响共享仓库。本机另有被忽略的 `个人工作区/` 用于草稿。
三者的区别见管理原则文件第 2 节。
