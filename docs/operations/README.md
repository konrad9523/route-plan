## 三点说明

**Issue/PR 模板必须留在 `.github/`，变更日志必须留在仓库根目录**——GitHub 从约定位置读取模板。这里只提供导航，**不复制模板内容**，避免产生两个需要同步的版本。

**角色成果区不在本目录**，而在共享仓库根目录的 [`workspaces/`](../../workspaces/)。
它按五个角色定制结构，用于放各角色的**阶段性成果**（全组可见）；制度说明见管理原则文件第 2、3 节。

**本机草稿不在共享仓库**：每人有一个被 `.gitignore` 排除的 `个人工作区/<角色>/`，
只在自己电脑上，不会上传。**想给全组看的成果就放进 `workspaces/<角色>/`，提交推送即可。**
两处的区别见管理原则文件第 2 节。
