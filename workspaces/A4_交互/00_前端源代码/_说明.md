# 前端源代码（索引页，不放代码副本）

## 为什么不在这里放代码

前端源码是**活的代码**，它只有一份，必须放在仓库的正式源码位置：

```
web/index.html          <- 前端页面（当前唯一入口）
api/main.py             <- 后端接口
```

如果把 `web/index.html` 复制一份到这里，立刻就会出现两个问题：

1. **两份副本会分叉** —— 改了真正在跑的那份，忘了改这份，别人照这份去理解就全错了。
2. **评审时不知道该看哪份** —— 老师或队友打开仓库，看到两处前端代码，无法判断哪个是交付物。

所以这个目录**只做索引和说明**，不放任何 `.html` / `.js` / `.css` 文件。

## 这个目录该放什么

- 前端代码的**入口说明**：哪个文件是入口、怎么启动、依赖什么。
- 关键逻辑的**讲解**（截图 + 文字），比如"这一行是为什么"。
- 与代码**同步维护**的架构图、数据流图。
- 变更记录：某次改动动了哪几个文件、为什么。

## 交付物在哪

前端本身作为课程交付物的一部分，直接看 `web/index.html`；
本目录的 `01_界面说明/` 负责解释它，`03_可视化结果/` 负责展示它的产出。
