## 三、本区结构

```text
workspaces/A5_验证/
├── README.md            # 本文件：职责 + 索引 + 状态
├── 01_实验方案/          # 每个实验：目的、数据、控制变量、步骤、指标
├── 02_验证结论/          # 结论 + 证据 + 局限性
└── 03_文档与答辩/        # 手册、报告、答辩材料的进度
```

### 01_实验方案

每个实验一个文件。**必须包含**（缺一项都会让结论不可信）：

| 项 | 说明 |
|---|---|
| 实验目的 | 要回答什么问题 |
| 实验数据 | 用哪个图、哪个查询集、多少组 |
| 控制变量 | 什么不变、什么在变 |
| 实验步骤 | 可复现的命令序列 |
| 评价指标 | 测什么、怎么算 |
| 预期结果 | 事先写下预期，事后对比 |
| 图表设计 | 出什么图、横纵轴是什么 |

### 02_验证结论

**结论必须带证据与局限**：

| 部分 | 要求 |
|---|---|
| 结论 | 一句话说清验证了什么 |
| 证据 | 命令 + 输出 + 数据文件位置 |
| 局限性 | 在什么条件下这个结论不成立 |
| 日期与环境 | 什么时候、在哪台机器上测的 |

> **诚实标注是本角色的核心价值**。没验证的不要说"已通过"；
> 推算的数字要标明是推算而非实测。
