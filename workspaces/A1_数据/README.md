### 01_路网清单

每个数据集一个文件，命名如 `campus_552.md`。**必须包含**：

| 项 | 示例 |
|---|---|
| 数据集名称 | `campus_552` |
| 规模 | 552 节点 / 1400 条有向边 |
| 覆盖范围 | 中国地质大学（武汉）周边约 3.7 × 3.6 km |
| 来源 | OSMnx 从 OpenStreetMap 抓取，2026-09-15 |
| 许可 | ODbL，© OpenStreetMap contributors |
| 生成命令 | `python learning_osmnx_networkx/route_demo.py --dist 1800` |
| 存储位置 | `data/campus_552.graphml` |
| 已知限制 | 约 48% 的边没有 geometry；25 个节点不在最大强连通分量内 |

### 02_字段与单位

**这是全组最容易踩坑的地方**，必须写清：

| 字段 | 单位 | 易错点 |
|---|---|---|
| `length_m` | 米 | — |
| `speed_kmh` | km/h | 不是 m/s，算法里要换算 |
| `cost`（shortest） | **米** | 与时间型偏好的 cost **不可直接比较** |
| `cost`（fastest 等） | **秒** | 同上 |
| `duration_s` | 秒 | 恒为秒，含转向惩罚，**可跨偏好比较** |
| `lon` / `lat` | WGS84 十进制度 | 顺序是 `(lon, lat)`，与部分地图 API 相反 |

### 03_数据质量

每次接入新数据集，产出一份体检结论。至少覆盖：

- 节点数 / 边数 / 最大强连通分量规模
- 不在最大强连通分量内的节点数（**演示时会"无路可达"**）
- 几何覆盖率
- `length / 端点直线距离` 的最小值（**小于 1 说明数据不自洽，会影响 A\* 最优性**）
- 重复边、孤立节点、异常限速

### 04_接口对接说明

**这是 A1 与其他角色之间的契约**，也是本角色最容易被忽视的产出。至少包含：

| 内容 | 说明 |
|---|---|
| **对外提供什么** | 数据文件路径、格式、字段、单位、坐标系 |
| **元信息位置** | `data/graph_meta.json` 的字段含义 |
| **谁在消费** | A2（算法读图）、A3（性能与测试）、A4（前端画图）、A5（演示引用）分别要什么 |
| **变更流程** | 字段/单位/路径变更时，提前通知谁、怎么通知 |
| **常见误用** | 单位混用（`cost` 随偏好单位不同）、坐标顺序、几何缺失的影响 |

> **接口对接说明不是"写给别人看的礼貌"，而是防止下游返工的护栏。**
> 例如"路网路径从 `learning_osmnx_networkx/output/` 迁到 `data/`"这件事，
> 如果没提前说明，4 处硬编码引用会同时断掉。

### 05_文档报告

数据相关的正式报告，例如：

- 路网数据集说明与质量评估报告
- 数据来源、许可与合规说明
- 大规模路网（10 万节点）接入报告

> 与 `docs/validation/` 的分工：**需要全组共同维护的正式结论进 `docs/`**，
> 本目录放**本角色视角**的汇总与索引。
