### 01_基准方法

**没有方法说明的数字不可信。** 必须写清：

| 项 | 要求 |
|---|---|
| 查询集 | 从哪个图、怎么采样、多少组、随机种子、文件在哪 |
| 预热 | 丢弃前几次（解释器预热、CPU 变频） |
| 重复次数 | 交错多轮、取中位数（**不要只跑一轮**） |
| 计时范围 | 只计算法核心；排除数据加载、几何构建、可视化 |
| 环境记录 | CPU / 内存 / Python 版本 / 操作系统 |
| 公平性 | 同图、同查询集、同代价模型；**预处理时间单列** |

### 02_基准结果

数据表 + 原始文件。至少包含：

| 指标 | 说明 |
|---|---|
| p50 / p95 / max | **不要只报单次最好成绩** |
| 扩展状态数 | 比耗时更本质 |
| 内存峰值 | 大规模下必需 |
| 一致性 | 与 Dijkstra 的代价是否一致 |

### 03_CH过程

| 指标 | 说明 |
|---|---|
| 预处理时间 | **必须与查询时间分开报** |
| 收缩顺序 | 是否复用（换权重时不重排序） |
| 捷径边数量 | 相对原始边数的比例 |
| 查询加速比 | 相对 A\* / Dijkstra |
| 解压正确性 | 捷径解压后的原始边序列是否与 Dijkstra 一致 |

> **必须记录的一条**：CH 依赖静态权重。交通权重变化时，
> 捷径边会失效并**给出错误结果**——必须显式回退到 A\* 并标注。
