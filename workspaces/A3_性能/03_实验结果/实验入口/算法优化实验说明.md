# 实验入口

算法保留在 [01_基准方法](../../01_基准方法/README.md)，日常规划不需要先运行 Notebook。

- [Dijkstra_pro.ipynb](notebooks/Dijkstra_pro.ipynb)：武汉 Dijkstra Python/C++ 分层实验。
- [Astar_pro.ipynb](notebooks/Astar_pro.ipynb)：武汉 A* 分层、启发式和消融实验。
- [run_shenzhen_experiments.py](run_shenzhen_experiments.py)：深圳复现实验。

完整实验需要 NumPy、SciPy、pandas、Matplotlib；Notebook 还使用 IPython/Jupyter。A2 基线位于 `workspaces/A2_算法/01_实现清单/`。C++ 构建产物仍放在 `01_基准方法/代码/.build/`，不上传 DLL；本机需准备相应编译环境及版本匹配的数据。

从仓库根目录运行深圳实验：

```powershell
python -B 'workspaces/A3_性能/03_实验结果/实验入口/run_shenzhen_experiments.py'
```

该命令执行完整实验，不是快速自检。原始快照见 [02_基准结果](../../02_基准结果/)，汇总见 [03_实验结果](../)，报告见 [05_文档报告](../../05_文档报告/)。Notebook 已保存的输出保留原路径与数字，不代表整理后重新测量。
