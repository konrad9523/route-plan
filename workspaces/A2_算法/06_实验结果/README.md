# 实验结果

对 **南山区、深圳市、广东省** 三种规模路网，分别使用 **100 对**和 **1000 对 OD** 比较 Dijkstra、A*、双向 A*、CH，合计六组已有结果。

| 路网 | 100 对 OD | 1000 对 OD |
|---|---|---|
| 南山区 | [`南山区（100对）/`](南山区（100对）/) | [`南山区（1000对）/`](南山区（1000对）/) |
| 深圳市 | [`深圳市（100对）/`](深圳市（100对）/) | [`深圳市（1000对）/`](深圳市（1000对）/) |
| 广东省 | [`广东省（100对）/`](广东省（100对）/) | [`广东省（1000对）/`](广东省（1000对）/) |

每组包含四个文件：

| 文件 | 内容 |
|---|---|
| `performance_dashboard.png` | 中文 2×2 性能对比图：查询耗时、扩展节点、预处理时间、总成本 |
| `algorithm_summary.csv` | 四算法汇总表：平均查询时间、平均扩展节点、预处理时间和总成本 |
| `query_raw.csv` | 每组 OD 的查询明细，包括起终点、代价、时间、扩展节点和有效性 |
| `summary.json` | 路网规模、测试参数、算法指标、预处理与缓存等结构化统计 |

**指标口径：** `总成本 = 预处理时间 + 平均查询耗时 × OD 数量`；时间单位毫秒。四算法性能结论与路网规模分析以 [`../07_文档报告/四种路径规划算法性能测试报告.docx`](../07_文档报告/四种路径规划算法性能测试报告.docx) 为准。

以上文件均由此前测试得到，整理时仅调整存放位置，没有修改数据或重新测试。
