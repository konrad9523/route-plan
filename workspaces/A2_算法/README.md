### 01_实现清单

每个算法一个文件，命名如 `astar.md`。**必须包含**：

| 项 | 示例 |
|---|---|
| 算法名与状态 | A\* · 已完成 |
| 入口函数 | `path_planning.router.plan_route(..., algorithm="astar")` |
| 状态空间 | `(previous_edge_id, node_id)` —— 为了表达转向限制 |
| 启发式 | Haversine 直线距离 ÷ 最大速度；**可采纳性已证明** |
| 时间复杂度 | O((V+E) log V) |
| 已知边界 | 几何不自洽的图上不保证最优（已提供 `check_heuristic_consistency()` 检测） |

### 02_正确性证据

**这是本角色最重要的产出。** 每实现一个算法，必须给出：

| 证据 | 做法 |
|---|---|
| 对拍 | 同一图、同一组起终点、同一代价模型，与 Dijkstra 比较 **cost**（不是 `edge_ids`） |
| 随机对拍 | 从最大强连通分量随机抽 300~400 组起终点 |
| 边界用例 | 起终点相同、等代价、自环、不可达、非法节点、单行道 |
| 可采纳性实验 | 抽样比较 `h(n)` 与真实剩余距离，证明 `h(n) ≤ 真实值` |

> **注意**：对拍要比较**代价**，不要比较边序列。
> 最短路径不唯一时两条都是最优解，比较 `edge_ids` 会误报失败。

### 03_算法对比

在**固定查询集**上比较各算法。至少包含：

| 指标 | 说明 |
|---|---|
| 路径是否相同 | 代价是否一致 |
| 总距离 / 总时间 | |
| 扩展状态数 | **最本质的效率指标** |
| 查询耗时 | p50 / p95 |
| 路径差异 | 与标准实现（如 NetworkX、OSRM）的偏差 |
