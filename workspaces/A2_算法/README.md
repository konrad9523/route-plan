## 性能对比概要

测试比较**平均查询耗时、扩展节点数、预处理时间与总成本**。从已有结果看，Dijkstra 查询开销一般较高；CH 在线查询速度有明显优势，但需要承担更高的预处理成本；A* 和双向 A* 位于两者之间。不同路网规模和 OD 数量下的综合成本需结合实验表和原报告判断。
