# 03_算法对比

各算法在搜索规模、扩展节点数、耗时上的横向对比。

---

## 目录结构

```
03_算法对比/
├── 对比代码/
│   ├── 1.扩展节点数对比.py
│   ├── 2.查询耗时对比.py
│   ├── 3.启发函数紧度.py
│   ├── 4.搜索空间可视化.py
│   └── 5.大规模路网压力测试.py
└── results/
    ├── 深圳/
    └── 华盛顿/
```

## 测试清单

| 测试 | 脚本 | 图来源 | 数据量 | 验证目标 |
|---|---|---|---|---|
| T1 | 1.扩展节点数对比.py | 真实路网 | 100 对起终点 | Dijkstra 与 A* 扩展节点数对比 |
| T2 | 2.查询耗时对比.py | 真实路网 | 100 对起终点，每对重复 3 次 | 查询耗时及启发系数一次性计算成本 |
| T3 | 3.启发函数紧度.py | 真实路网 | 20 个终点 × 每终点 100 个节点 | Haversine 启发值与真实剩余代价对比 |
| T4 | 4.搜索空间可视化.py | 真实路网 | 1 对起终点 | 搜索范围静态图和 A* 动画 |
| T5 | 5.大规模路网压力测试.py | 真实路网 | 100 对起终点，按距离分档 | 按起终点直线距离观察性能 |

T1~T5 全部使用真实路网，验证真实规模下的性能表现。

> 注意：本目录的 T1~T5 与 02_正确性证据目录的 T1~T6 是两套独立编号，不要混淆。

## 运行方式

从项目根目录执行，例如：

```powershell
# 默认深圳
python .\workspaces\A2_算法\03_算法对比\对比代码\1.扩展节点数对比.py --pairs 100
python .\workspaces\A2_算法\03_算法对比\对比代码\2.查询耗时对比.py --pairs 100 --repeats 3
python .\workspaces\A2_算法\03_算法对比\对比代码\3.启发函数紧度.py --targets 20 --nodes-per-target 100
python .\workspaces\A2_算法\03_算法对比\对比代码\4.搜索空间可视化.py
python .\workspaces\A2_算法\03_算法对比\对比代码\5.大规模路网压力测试.py --pairs 100

# 指定华盛顿
python .\workspaces\A2_算法\03_算法对比\对比代码\1.扩展节点数对比.py --network washington --pairs 100
python .\workspaces\A2_算法\03_算法对比\对比代码\2.查询耗时对比.py --network washington --pairs 100 --repeats 3
python .\workspaces\A2_算法\03_算法对比\对比代码\3.启发函数紧度.py --network washington --targets 20 --nodes-per-target 100
python .\workspaces\A2_算法\03_算法对比\对比代码\4.搜索空间可视化.py --network washington
python .\workspaces\A2_算法\03_算法对比\对比代码\5.大规模路网压力测试.py --network washington --pairs 100
```

## 参数说明

| 参数 | 说明 | 适用 |
|---|---|---|
| --network | 选择路网，默认 shenzhen | T1~T5 |
| --graphml | 直接指定 GraphML 路径，覆盖 --network | T1~T5 |
| --pairs | 随机起终点对数，默认 100 | T1、T2、T5 |
| --repeats | 每查询重复次数，默认 3 | T2 |
| --targets | 抽样终点数量，默认 20 | T3 |
| --nodes-per-target | 每终点抽样节点数，默认 100 | T3 |
| --seed | 随机种子，默认 42 | T1~T5 |
| --output-dir | 输出目录，不传时按路网自动命名 | T1~T5 |
