# 算法对比测试代码

本目录的脚本分别运行 T1–T5（本目录内部编号）；运行某个脚本不会调用其他测试。结果文件写入上一级 `results/`。公共工具放在 `02_正确性证据/测试代码/_common/`。

| 本目录编号 | 脚本 | 图来源 | 数据量 | 内容 |
|---|---|---|---|---|
| T1 | `1.扩展节点数对比.py` | 真实路网 | 100 对起终点 | Dijkstra 与 A* 扩展节点数对比 |
| T2 | `2.查询耗时对比.py` | 真实路网 | 100 对起终点，每对重复 3 次 | 查询耗时及启发系数一次性计算成本 |
| T3 | `3.启发函数紧度.py` | 真实路网 | 20 个终点 × 每终点 100 个节点 | Haversine 启发值与真实剩余代价对比 |
| T4 | `4.搜索空间可视化.py` | 真实路网 | 1 对起终点 | 搜索范围静态图和 A* 动画 |
| T5 | `5.大规模路网压力测试.py` | 真实路网 | 100 对起终点，按距离分档 | 按起终点直线距离观察性能 |

T1–T5 全部使用真实路网，验证真实规模下的性能表现。

> 注意：本目录的 T1–T5 与 `02_正确性证据` 目录的 T1–T6 是两套独立编号，不要混淆。

从项目根目录运行，例如：

```powershell
python .\workspaces\A2_算法\03_算法对比\测试代码\1.扩展节点数对比.py --pairs 100
python .\workspaces\A2_算法\03_算法对比\测试代码\2.查询耗时对比.py --pairs 100 --repeats 3
python .\workspaces\A2_算法\03_算法对比\测试代码\3.启发函数紧度.py --targets 20 --nodes-per-target 100
python .\workspaces\A2_算法\03_算法对比\测试代码\4.搜索空间可视化.py
python .\workspaces\A2_算法\03_算法对比\测试代码\5.大规模路网压力测试.py --pairs 100
