# 接口说明（前端调用）

默认地址：`http://127.0.0.1:8000`
交互文档：`http://127.0.0.1:8000/docs`
启动：先 `python api.py --prepare` 生成缓存，再 `python api.py --serve`。

前端只需要本文件、接口地址和一份示例结果；不需要读 C++ 算法、A1 路网或缓存文件。

---

## 1. 调用流程

1. `GET /api/config`：读取数据集、算法、默认参数和缓存开关。
2. `GET /api/cache/status`：确认所选路网的缓存已准备好。
3. `POST /api/benchmarks`：提交测试，拿到 `job_id`。
4. `GET /api/jobs/{job_id}`：轮询进度，直到 `completed`。
5. 读取 `summary`、`table`、`table.csv`、`dashboard`、`queries`。

## 2. 端点总表

| 方法 | 路径 | 前端传入 | 后端返回 |
|---|---|---|---|
| GET | `/api/config` | 无 | 算法、路网、默认参数、缓存策略 |
| GET | `/api/cache/status` | 无 | 各数据集缓存可用性、原因、时间、预处理耗时 |
| POST | `/api/benchmarks` | 数据集、算法列表、查询数、重复次数、种子 | `job_id`、排队状态 |
| GET | `/api/jobs/{job_id}` | `job_id` | 状态、阶段、百分比、错误或结果地址 |
| GET | `/api/results/summary` | 无 | 路网、查询参数、P50/P95、各算法统计、校验结果 |
| GET | `/api/results/table` | 无 | 五列汇总表 JSON |
| GET | `/api/results/table.csv` | 无 | 五列汇总表 CSV 下载 |
| GET | `/api/results/dashboard` | 无 | 2×2 中文综合图 PNG |
| GET | `/api/results/queries` | `offset`、`limit` | 分页 OD 明细 |

## 3. 提交测试

`POST /api/benchmarks`

```json
{
  "dataset": "nanshan",
  "algorithms": ["dijkstra", "astar", "bidirectional_astar", "ch"],
  "query_count": 300,
  "repeat": 3,
  "seed": 20261102
}
```

| 字段 | 取值 | 说明 |
|---|---|---|
| `dataset` | `nanshan` / `shenzhen` / `guangdong` | 数据集 ID |
| `algorithms` | 四个算法 ID 的任意子集 | 至少一个，重复项会自动去重 |
| `query_count` | 3–10000 | OD 对数 |
| `repeat` | 1–20 | 每对重复次数 |
| `seed` | 0–4294967295 | 固定随机种子，可复现 |

成功返回 `202` 和 `job_id`；缓存未就绪返回 `409`，由后端运行 `python api.py --prepare`，前端不要提供重建按钮。

## 4. 页面参数与控件

| 控件 | 参数 |
|---|---|
| 数据集下拉框 | `dataset` |
| 算法多选 | `dijkstra` / `astar` / `bidirectional_astar` / `ch` |
| 查询数 | `query_count` |
| 重复次数 | `repeat` |
| 随机种子 | `seed` |

页面流程：`GET /api/config` → `POST /api/benchmarks` → 轮询 `GET /api/jobs/{job_id}` → 完成后同时展示 `GET /api/results/dashboard` 与 `GET /api/results/table`。

## 5. 结果数据

每次运行生成四个文件，接口读的就是它们：

| 文件 | 内容 |
|---|---|
| `summary.json` | 路网规模、查询参数、各算法 P50/P95/扩展/预处理/索引、校验结果 |
| `algorithm_summary.csv` | 算法、平均查询耗时、平均扩展节点、预处理时间、总成本 |
| `performance_dashboard.png` | 查询耗时、扩展节点、预处理成本、总成本 2×2 图 |
| `query_raw.csv` | 每条 OD × 每个算法的原始记录 |

`queries` 每行包含：起点、终点、路径成本、查询耗时、扩展节点、入队次数、路径边数；**不含**完整路径节点和道路几何，不能用于地图画线。

图表中的预处理时间来自缓存首次构建时的记录；前端查询时不会重复执行预处理。

## 6. 错误码

| 状态 | 场景 | 前端处理 |
|---|---|---|
| `400` | 数据集未知、算法参数无效 | 提示参数错误 |
| `404` | `job_id` 不存在、结果文件未生成 | 提示任务不存在或先提交测试 |
| `409` | 预处理缓存未就绪 | 提示“预处理缓存尚未准备”，不提供重建按钮 |

## 7. 能力边界

- 同一时间只执行一个测试任务，后续任务排队。
- 后端重启后内存中的 `job_id` 失效，但结果文件仍保留。
- 结果按来源写到 `结果/self_test/`（自测）或 `结果/frontend/`（接口），新任务会覆盖上一次的四个文件。
- 服务绑定 `127.0.0.1`，只本机可用；跨机器调用需要改监听地址并配置网络。
